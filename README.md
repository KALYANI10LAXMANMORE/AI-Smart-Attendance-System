# 🚀 AI Smart Attendance System

An advanced AI-powered attendance management system developed using Python, Streamlit, OpenCV, and Face Recognition technology.

The system automatically detects student faces through a live camera and marks attendance in real time with a smart and attractive dashboard UI.

---

# ✨ Features

- 🎥 Real-time Face Recognition
- ✅ Automatic Attendance Marking
- 📊 Present & Absent Dashboard
- 📅 Timetable Based Attendance
- 🧠 AI Powered Smart UI
- 🚨 Unknown Face Detection
- 📈 Attendance Percentage Analytics
- ⬇ Download Attendance CSV
- ⚡ Fast Camera Processing
- 🔥 Modern Attractive Interface

---

# 🛠 Technologies Used

- Python
- Streamlit
- OpenCV
- Face Recognition
- NumPy
- Pandas
- PIL
